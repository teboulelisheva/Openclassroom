# Puls-Events RAG — Assistant Intelligent Culturel

POC d'un système RAG pour recommandations d'événements culturels parisiens.

## Stack technique
- **Données** : API open data Ville de Paris (Que faire à Paris)
- **Embeddings** : Mistral Embed API
- **Vectorstore** : FAISS (CPU)
- **LLM** : Mistral Small
- **API** : FastAPI
- **Conteneur** : Docker

## Structure

```
puls-events-rag/
├── api/
│   └── main.py          # API FastAPI
├── scripts/
│   └── build_index.py   # Construction index FAISS
├── notebooks/
│   └── system_rag.ipynb # Notebook de développement Colab
├── tests/
│   └── test_api.py      # Tests unitaires
├── vectorstore/         # Index FAISS (généré par build_index.py)
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
└── .env.example
```

## Lancement rapide

### 1. Configuration
```bash
cp .env.example .env
# Editer .env et renseigner MISTRAL_API_KEY
```

### 2. Installation locale
```bash
pip install -r requirements.txt
```

### 3. Build de l'index FAISS
```bash
python scripts/build_index.py
```

### 4. Lancer l'API en local
```bash
uvicorn api.main:app --host 0.0.0.0 --port 8000
```

### 5. Ou via Docker
```bash
docker build -t puls-events-rag .
docker run -p 8000:8000 --env-file .env puls-events-rag
```

### 6. Tester l'API
```bash
# Health check
curl http://localhost:8000/health

# Poser une question
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "Quels concerts ont lieu a Paris ?", "k": 3}'
```

Documentation interactive : http://localhost:8000/docs

### 7. Tests unitaires
```bash
pytest tests/
```

## Endpoints

| Methode | Route | Description |
|---------|-------|-------------|
| GET | /health | Etat de l'API et de l'index |
| POST | /ask | Question -> reponse RAG |
| POST | /rebuild | Recharge l'index depuis le disque |
| GET | /docs | Swagger UI |
